# v1 双路上行语义调度方案

> **版本**：v1.0-draft  
> **日期**：2026-08-06  
> **定位**：Go2 + Orin NX（端侧）↔ RTX 5070（边侧）的 **RGB 流 + 子图流** 双路上行、SemanticDirective 下行的最小可跑通方案。  
> **motion 体系对齐**：见 [`RGB_ws/docs/v1-motion体系对齐说明.md`](../RGB_ws/docs/v1-motion体系对齐说明.md)（统筹仓 `motion/`、实现仓 `motion_ws/`、本仓、Go2 四仓对照）。  
> **前提【事实】**：端侧 Super-LIO、局部子图生命周期管理、BT-scan-planner 已跑通。  
> **关联**：`motion/02-架构设计/Go2端侧-可闭环易解释系统工程.md` · `motion_ws/scripts/submap_uplink/protocol.py` · `RGB_ws/README.md`（StreamVLN 可选支路）

---

## 1. 一句话

端侧继续以 **Super-LIO + BT-scan-planner** 为控制闭环一等公民；边侧只做 **收两路流 → 时间对齐 → 语义推理 → 下发 SemanticDirective**，由 BT 对 frontier 加权，不直接发 `/cmd_vel`。

---

## 2. v1 边界

### 2.1 做什么

| 项 | 内容 |
|----|------|
| 上行路 1 | **子图流**：稀疏子图快照 + frontier 列表（低带宽 JSON） |
| 上行路 2 | **RGB 流**：H.265 硬件编码（NVENC，15fps）→ 边侧 NVDEC；联调初期可用 JPEG 1Hz 过渡 |
| 边侧 | 维护子图索引 + 关键帧缓存；单次语义查询；输出 SemanticDirective |
| 下行 | SemanticDirective over UDS/TCP |
| 端侧 | BT 消费 directive，加权 frontier；Super-LIO 高频闭环不变 |

### 2.2 不做什么（v1 明确排除）

- 边侧重建占据栅格 / 全局位姿图（几何真值在端侧）
- StreamVLN 慢流体素记忆 + 单目深度融合
- MTU3D / ConceptGraphs 对象级场景图
- 15fps 全流进 7B 模型推理
- VLM/VLN 直接控制 Go2 运动

## 4. 双路协议

### 4.1 子图流：`motionslam.sparse_subgraph.v1`

**传输**：TCP/UDS，UTF-8 JSON，建议独立端口 `9877`（与现有 SUBM1 点云端口 `9876` 分离）。

**频率**：

- 常态 **1 Hz** 周期快照
- BT 触发 `REQUEST_SEMANTIC_REPLAN` 时 **立即补发一帧**（带 `trigger_reason`）

**示例**：

```json

  "version": 42,
  "session_id": "local_session",
  "map_id": "building_01/floor_01",
  "timestamp_ns": 1785316341822379350,
  "frame_id": "map",
  "robot_pose": { "x": 1.17, "y": -0.23, "z": 0.0, "yaw_rad": 0.10 },

  "nodes": [
    {
      "node_id": "cell_12_8",
      "centroid": { "x": 3.2, "y": 1.1, "z": 0.0 },
      "visited": false,
      "frontier_count": 2,
      "occupancy_summary": { "free_ratio": 0.62, "unknown_ratio": 0.28 },
      "rgb_keyframe_ref": "kf_00017"
    }
  ],

  "edges": [
    { "src": "cell_12_8", "dst": "cell_13_8", "type": "adjacent", "cost_m": 0.5 }
  ],

  "frontiers": [
    {
```

**与现有 SUBM1 的关系**：

- `motionslam.submap_tile.v1` + SUBM1 点云：**保留**，用于调试/Foxglove/离线拼接
- v1 语义调度 **不依赖点云上行**，只依赖上述 JSON 快照
- 节点 `node_id` 建议与端侧子图生命周期管理器的 tile/cell ID 一致

### 4.2 RGB 流：`motionslam.rgb_h265.v1`（推荐）

**端侧管道**：Linux SHM → EGL/NvBuf → **NVENC (nvv4l2h265enc)** → H.265 码流上行。  
**边侧管道**：**NVDEC** 解码 → 关键帧环缓冲 → VLM 按 1–4 Hz 取帧（不对 15fps 全流推理）。

详细实现见：[`v1-RGB硬件编码上行方案.md`](./v1-RGB硬件编码上行方案.md)

**传输**（联调）：TCP 长度前缀；生产可改 RTP/UDP。

```text
H265K1 | u32 json_len | json_utf8 | u32 au_len | h265_access_unit_bytes
```

**频率**：

- 相机 → SHM：**15 fps**
- 码流上行：**15 fps**（H.265，2–4 Mbps 典型）
- 语义取帧：**1–4 Hz**（边侧从解码缓冲抽取，与子图 version 对齐）
- 联调过渡：可用 `motionslam.rgb_keyframe.v1`（JPEG 1Hz，RGBK1）先打通协议

**侧车 JSON 示例**：

```json
{
  "schema": "motionslam.rgb_h265.v1",
  "keyframe_id": "kf_00017",
  "session_id": "local_session",
  "subgraph_version": 42,
  "timestamp_ns": 1785316340000000000,
  "pose": { "x": 1.1, "y": -0.2, "yaw_rad": 0.10 },
  "width": 640,
  "height": 480,
  "fps": 15,
  "codec": "h265",
  "is_idr": true
}
```

### 4.3 下行：`motionslam.semantic_directive.v1`

```json
{
  "schema": "motionslam.semantic_directive.v1",
  "map_version": 42,
  "session_id": "local_session",
  "issued_at_ns": 1785316350000000000,
  "ttl_ms": 3000,

  "target_subgraph_node_id": "cell_13_8",
  "candidate_frontier_ids": ["fr_003", "fr_007"],
  "exploration_bias": "BIAS_TOWARD_SUBGRAPH_NODE",
  "subgraph_confidence": 0.78,

  "room_found": false,
  "found_room_type": "",

  "natural_language_explanation": "Corridor to the left likely leads to kitchen area."
}
```

**端侧校验规则（必须实现）**：

1. `map_version <= 本地当前 version` 且 `|issued_at - now| < ttl_ms`
2. `candidate_frontier_ids` 均存在于本地 frontier 表，否则丢弃并打日志
3. 过期 directive 不得影响 BT 几何分

**`exploration_bias` 枚举（v1）**：

| 值 | BT 行为 |
|----|---------|
| `BIAS_TOWARD_SUBGRAPH_NODE` | 提高 `target_subgraph_node_id` 关联 frontier 权重 |
| `BIAS_AWAY_FROM_VISITED` | 降低已访问 node 关联 frontier 权重 |
| `BIAS_INTO_OPEN_SPACE` | 提高 `free_ratio` 高节点 frontier 权重 |
| `BIAS_STOP_AND_CONFIRM` | BT 进入停等确认子树 |
| `BIAS_NONE` | 仅几何分 |

## 5. 边侧模块（5070）

| 模块 | 职责 | v1 优先级 |
|------|------|-----------|
| `SubgraphReceiver` | 解析 JSON，更新 `latest_subgraph` | P0 |
| `RgbReceiver` | 解码 RGBK1，写入 ring buffer | P0 |
| `Aligner` | `|t_rgb - t_subgraph| < 500ms` 且 version 一致 | P0 |
| `FrameSelector` | 按指令从 nodes 选 ≤4 张关键帧（MSGNav 风格动态分配简化版） | P0 |
| `SemanticScheduler` | Qwen2.5-VL-7B INT4 推理 → SemanticDirective | P0 |
| `DirectivePublisher` | TCP/UDS 下行 | P0 |
| `StreamVLN`（RGB_ws） | 可选 action bias | P1 |

### 5.1 边侧推理流程（伪代码）

```python
def on_subgraph(snapshot):
    store[snapshot.version] = snapshot
    maybe_schedule_query(snapshot)

def on_rgb_keyframe(kf, jpeg):
    buffer[kf.keyframe_id] = (kf, jpeg)
    maybe_schedule_query(kf)

def maybe_schedule_query(trigger):
    snap = latest_aligned_subgraph()
    frames = select_frames(snap, instruction, budget=4)
    if not frames:
        return
    directive = qwen_vl_infer(snap, frames, instruction)
    publish_directive(directive)
```

### 5.2 5070 资源预算

| 组件 | 估计 |
|------|------|
| Qwen2.5-VL-7B INT4 | 显存 ~6–8 GB，推理 1–3 s/次 |
| 子图 + 关键帧缓存 | CPU / <500 MB RAM |
| 查询频率 | 0.2–1 Hz（BT 触发 + 周期上限） |

StreamVLN 与 Qwen-VL **v1 不要同 tick 并行**；若启用 StreamVLN，串行或降频。

## 6. BT 融合公式（v1）

```text
frontier_score(f) =
    w_geom  * f.geom_score
  + w_graph * graph_bias(f, directive)
  + w_conf  * directive.subgraph_confidence

graph_bias(f, d) =
    1.0  if f.attached_node_id == d.target_subgraph_node_id
    0.5  if f.frontier_id in d.candidate_frontier_ids
    0.0  otherwise
```

默认权重建议：`w_geom=0.6, w_graph=0.3, w_conf=0.1`（需真机标定）。

**原则**：语义只做 **软偏置**；几何不可达时 BT 仍可按纯 geom 走。

## 7. 时序与对齐

```text
T0  端侧 Super-LIO 更新 local submap + frontiers
T1  同一 tick：SubgraphPublisher 发 snapshot(v=42)
T2  ±100ms：RgbKeyframeUplink 发 kf_00017 (subgraph_version=42)
T3  边侧 Aligner 确认配对 → 触发语义查询
T4  边侧下发 SemanticDirective(map_version=42, ttl=3s)
T5  端侧 DirectiveReceiver 校验 → 写入 BT blackboard
T6  BT 下一 planning cycle 使用新权重选 frontier
T7  Super-LIO + scan-planner 执行局部路径
```

## 9. v1 验收标准

> **完整验证体系**（专网 VLN、任务成功率 SR、边端流畅性 G1–G4）见 **`[v1-技术验证标准.md](./v1-技术验证标准.md)`**。本节为模块级快速检查项。

| # | 验收项 | 通过条件 |
|---|--------|----------|
| A1 | 子图流稳定 | 1 Hz 连续 10 min 无 parse 错误 |
| A2 | RGB-子图对齐 | 同 version 配对率 > 95% |
| A3 | 边侧推理 | 单次查询 < 5 s（5070） |
| A4 | 下行有效 | BT 日志可见 frontier 权重变化 |
| A5 | 闭环不断 | Super-LIO 控制频率不因边侧阻塞而下降 |
| A6 | 过期丢弃 | 注入过期 directive，BT 不得误用 |
| A7 | **专网 VLN** | 标准任务包 SR_subgoal ≥ 80%，frontier@1 ≥ 75%（见验证标准 §5） |
| A8 | **流畅性** | 专网 30 min 联调 E1–E4、S1–S3 达标（见验证标准 §4） |
