## 1. 端侧 v1 目标

在 **不改变 Super-LIO 控制闭环、不替换 BT-scan-planner 一等公民地位** 的前提下，新增：

1. **子图流上行** — 把现有子图/frontier 状态序列化为 JSON 发给边侧
2. **RGB 关键帧上行** — 与 snapshot 时间/version 对齐
3. **SemanticDirective 下行接收** — 校验后注入 BT 黑板
4. **BT frontier 加权扩展** — 消费语义偏置，与几何分融合

## 3. 任务清单（按优先级）

### P0 — 阻塞 v1 联调

#### T-P0-1：SubgraphPublisher（子图流上行）

**输入**：子图生命周期管理器当前快照（nodes / frontiers / robot_pose / version）

**输出**：`motionslam.sparse_subgraph.v1` JSON → TCP `边侧IP:9877`

**实现要点**：

- [ ] 从现有 submap/tile 管理器 **只读** 拉快照，不 duplicate 建图逻辑
- [ ] `node_id` 与本地 lifecycle ID 一致，便于 BT 回查
- [ ] `frontiers[]` 直接来自 scan-planner 当前 frontier 表（含 `geom_score`）
- [ ] 每个 node 填 `rgb_keyframe_ref`（指向最近关键帧）
- [ ] 1 Hz 定时 + BT 触发立即发送（`trigger_reason` 字段）
- [ ] 断线重连：保留 `session_id`，`version` 单调递增

**验收**：边侧收到 JSON 可 parse；Foxglove/日志可打印 node/frontier 数量。

---

#### T-P0-2：RgbH265Uplink（RGB 硬件编码上行）

**输入**：Linux SHM 环形缓冲（15fps，建议 NV12）

**输出**：H.265 码流 → `:9878`（NVENC）；联调初期可 fallback JPEG/RGBK1

**实现要点**：

- [ ] SHM → **NvBuf/EGL 零拷贝** → `nvv4l2h265enc`（GStreamer 或 Jetson Multimedia API）
- [ ] **不用 Argus**（除非改为 CSI 直采）；SHM 路径用 `shmsrc/appsrc → nvvidconv → nvv4l2h265enc`
- [ ] 码率 2–4 Mbps，GOP=15（1s IDR），640×480 @ 15fps
- [ ] 侧车 JSON（H265K1）带 `subgraph_version`、`keyframe_id`、`timestamp_ns`、`pose`、`is_idr`
- [ ] 编码线程独立、发送队列有界；网络阻塞时丢 P 帧，**不反压 Super-LIO/BT**
- [ ] `keyframe_id` 与子图 snapshot 的 `keyframes_meta` 对齐

**边侧（5070）配套**：

- [ ] NVDEC 解码（`nvv4l2decoder` / FFmpeg `hevc_cuvid`）
- [ ] 解码帧入 ring buffer；VLM **1–4 Hz 取帧**，不对 15fps 全推理

**验收**：

- [ ] `tegrastats`：编码时 Super-LIO 帧耗时不退化；编码 CPU **<10%**（目标 <5%）
- [ ] 边侧 NVDEC 单帧 p99 **<2 ms**（不含网络）
- [ ] `subgraph_version` 与子图流一致

**详见**：`[v1-RGB硬件编码上行方案.md](./v1-RGB硬件编码上行方案.md)`

---

#### T-P0-3：DirectiveReceiver（语义指令下行）

**输入**：TCP `边侧IP:9879` 监听到连接，或端侧主动 pull（二选一，建议 **边侧 push / 端侧 listen**）

**输出**：校验通过的 `SemanticDirective` → BT blackboard

**实现要点**：

- [ ] 校验 `map_version <= local_version`
- [ ] 校验 `ttl_ms` 未过期
- [ ] 校验 `candidate_frontier_ids` 在本地 frontier 表存在
- [ ] 失败打结构化日志（`REJECT_EXPIRED` / `REJECT_VERSION` / `REJECT_UNKNOWN_FRONTIER`）
- [ ] 线程安全写入 BT blackboard（读写锁或 ROS2 话题中转）

**验收**：注入 mock directive，BT 黑板可读；过期 directive 被丢弃。

---

#### T-P0-4：BT-scan-planner 语义加权扩展

**输入**：BT blackboard 上最新 `SemanticDirective`

**输出**：修改后的 `frontier_score`

**实现要点**：

- [ ] 新增 blackboard 键：`/semantic/directive`、`/semantic/valid`
- [ ] 在现有 frontier 评分处增加 `graph_bias(f, directive)`（见方案文档 §6）
- [ ] `directive` 无效或过期时 **fallback 纯几何分**
- [ ] 可选：新增 BT 条件节点 `HasValidSemanticDirective`
- [ ] 触发重规划：frontier 长时间不变 / 用户新指令 → 设 `REQUEST_SEMANTIC_REPLAN=true` → SubgraphPublisher 立即补发

**验收**：同一 frontier 集，有/无 directive 时 BT 选择不同目标（日志可证）。

---

#### T-P0-5：网络与配置

- [ ] `config/edge_uplink.yaml`（或等价）：边侧 IP、端口 9877/9878/9879、上行频率
- [ ] 防火墙放行（开发机侧，参考 `motion_ws/hosts.md`）
- [ ] 弱网：发送失败不阻塞 Super-LIO / BT 主线程（独立 IO 线程 + 队列）

**验收**：断网 30 s 后恢复，Super-LIO 与 BT 仍正常运行。

## 4. 模块接口草案（端侧内部）

### 4.1 SubgraphSnapshotProvider（已有逻辑上暴露接口）

```cpp
// 从现有子图生命周期管理器只读导出
struct SubgraphSnapshot {
  uint64_t version;
  string session_id;
  Pose robot_pose;
  vector<Node> nodes;
  vector<Edge> edges;
  vector<Frontier> frontiers;
  vector<KeyframeMeta> keyframes_meta;
  string trigger_reason;  // "periodic" | "bt_replan" | "manual"
};
```

### 4.2 BT Blackboard 键（新增）


| 键                          | 类型                | 写入方               | 读取方               |
| -------------------------- | ----------------- | ----------------- | ----------------- |
| `/semantic/directive`      | SemanticDirective | DirectiveReceiver | FrontierScorer    |
| `/semantic/valid`          | bool              | DirectiveReceiver | FrontierScorer    |
| `/semantic/request_replan` | bool              | BT 条件节点           | SubgraphPublisher |


### 4.3 FrontierScorer 扩展

```text
// 现有
score = geom_score(f)

// v1
if blackboard[/semantic/valid]:
  score = w_geom * geom_score(f)
        + w_graph * graph_bias(f, directive)
        + w_conf * directive.confidence
else:
  score = geom_score(f)
```

## 8. 风险与缓解


| 风险                   | 缓解                     |
| -------------------- | ---------------------- |
| RGB 与子图 version 不一致  | 同 tick 触发；不对齐则边侧不推理    |
| directive 过期仍被 BT 使用 | TTL + version 双校验      |
| 上行 IO 阻塞主线程          | 独立 publisher 线程 + 有界队列 |
| frontier_id 边端幻觉     | 端侧校验 unknown id 整包丢弃   |
| 语义与几何冲突              | 语义仅加权，不硬覆盖不可达 frontier |
